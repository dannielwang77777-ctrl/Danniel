Run The City. 让四海城成为广州半山跑步生活方式地标

四海Runner 不是一次活动，而是一套面向跑者、亲子家庭、宠物友好人群和运动品牌的长期社群资产。以「四海Runner Station 跑步驿站」作为物理载体，把咖啡、存包、休息、产品展示、路线集合和内容传播串成可持续商业闭环。

01 / Position

Not A Run Club. A Sport Lifestyle Platform.

国际运动品牌的项目逻辑不是“办热闹”，而是建立身份、训练、内容和商业回报。四海Runner 的定位应从跑团升级为广州本地运动生活方式平台。

Community

免费社群跑，建立城市跑者心智

每周三夜跑、周六晨跑、周日亲子/宠物友好跑。免费入口负责拉新、留存和内容生产。

Training

付费训练营，让社群具备自我造血

5K 入门、10K 进阶、半马备赛、Hyrox 体能训练，形成从兴趣到训练的升级路径。

Commerce

品牌赞助和商户核销，形成可衡量回报

跑鞋试穿、装备测评、跑后餐饮券、咖啡券、季度赛事报名，帮助四海城看到真实数据。

02 / Physical Base

SiHai Runner Station. The Base Before And After Every Run.

跑步社群要长期运营，必须有一个线下锚点。四海Runner Station 可以是四海城里的“跑步驿站”：跑前集合、存包、喝咖啡、休息、产品试穿、路线发布、品牌展示和内容拍摄都在这里发生。

03 / Reference Case

Hysan Proved The Mall Can Be The Base.

希慎 Hysan Running Club 的启发是：商场不只是场地，而是跑者集合、存包、补给、社交、内容和品牌体验的基地。四海城拥有更强的自然条件，可以做广州版本。

例子一 周三 7KM 城市夜跑：四海城集合，分配速组，跑后导入酒吧或轻食商户。
例子二 品牌试跑夜：On / HOKA / Salomon 提供试穿，跑者完成路线后提交体验笔记。
例子三 跑后 DJ / Drink Session：把运动结束后的兴奋感转化为社交和夜经济。
04 / XHS Case

Creative Content Makes The Business Sustainable.

用户提供的小红书案例「壹个跑步生意的诞生：超会买的娇总」强调：成熟社区、城市自然路线、创意内容和商业合作，是跑步社群可持续的关键。

对四海城 半山高差、生态绿地、万博 CBD、餐酒咖啡业态，刚好能承接“城市到自然”的路线叙事。
对跑者 跑步不只是训练，也是一套装备、路线、照片、朋友和周末生活方式。
对商业 从内容种草到装备试穿、从跑后消费到季度赛事，商业不破坏社群，反而让社群更稳定。
05 / Running Flow

From Route To Revenue.

每一场活动都按照同一套运营动作执行，方便复制、复盘和招商。

01

集合签到

02

分组开跑

03

跑后消费

咖啡、轻食、餐酒、酒吧、运动装备券，现场核销并沉淀数据。

04

内容裂变

照片、vlog、路线图、小红书笔记和品牌联名内容，驱动下一次报名。

09 / 90-Day Pilot

Start Small. Measure Everything.

建议先用 90 天试运营替代直接年度大预算。让四海城先看到报名、到场、核销、内容曝光和商户反馈。

Week 1-2

筹备与路线实测

  • 确认集合点、存包点、风险点
  • 完成视觉系统和路线图
  • 确定首批商户福利
Week 3-6

冷启动社群跑

  • 每周 2 场固定跑
  • 每场 30-60 人目标
  • 活动照片和小红书内容复盘
Week 7-10

主题活动放大

  • 亲子跑、宠物友好跑
  • 品牌试跑或装备体验
  • 商户券核销数据沉淀
Week 11-12

复盘与季度赛事

  • 输出 90 天数据报告
  • 提出四海半山挑战赛
  • 升级年度合作框架
